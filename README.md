# Gabor Boglar

### Legacy Software Engineer

I work with business-critical software that is still doing its job long after the original technology, documentation, development environment — or even the original developer — has disappeared.

My focus is not replacing old software simply because it is old. I help understand, recover, repair and modernize systems that businesses still depend on.

## What I work with

- **VB6** and classic Windows applications
- **Delphi** legacy systems
- **RS-232 / serial communication**
- **Legacy databases and data recovery**
- **Software archaeology**
- **Reverse engineering undocumented systems**
- **Software recovery without source code**
- **Legacy hardware and software integration**

## Typical problems

- A critical application no longer runs on modern Windows
- Source code or parts of the development environment are missing
- DLL, OCX, COM or other dependencies are unavailable
- Nobody fully understands how an old application works
- A legacy database contains valuable business data
- An undocumented serial device or protocol must be integrated
- The original developer is no longer available
- A working legacy system needs to be maintained or modernized without unnecessary replacement
